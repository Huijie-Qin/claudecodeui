# Agent 模板文件存储

Agent 模板高级配置上传的文件保存在服务器文件系统。SQLite 中的模板和工作空间快照只保存文件夹名称、目录结构、文件相对路径、字节大小、SHA-256 校验值和文件夹版本。新上传文件在请求中仍通过 Base64 传输，保存后不再保留 Base64 内容。

## 配置存储根路径

在 `.env` 中配置绝对路径，重启服务后生效：

```dotenv
CLOUDCLI_AGENT_TEMPLATE_ASSETS_ROOT=/data/db/agent-template-assets
```

未配置时，按以下优先级选择目录：

1. `${CLOUDCLI_DATA_ROOT}/agent-template-assets`
2. `${DATABASE_PATH 所在目录}/agent-template-assets`
3. `${应用根目录}/data/agent-template-assets`

配置目录需要允许服务进程读写；不能设置为文件系统根目录。Docker 部署应将它放在已持久化挂载的目录内，或为自定义目录增加宿主机与容器同路径的绑定挂载。

## 文件布局与使用

文件按内容校验值保存：

```text
<存储根路径>/objects/<SHA-256 前两位>/<完整 SHA-256>
```

相同内容只存一份。选择模板创建工作空间时，服务校验文件大小和内容，并按模板记录的目录结构将文件写入 `<工作空间>/.claude/<上传文件夹名称>/`。模板文件与工作空间文件互相独立，修改工作空间里的文件不会改变模板。

## 旧数据迁移与备份

启动时会自动迁移模板和工作空间快照中原有的 Base64 数据。每条记录都先成功保存文件，再替换数据库中的内容；失败记录保留原始数据并记录错误，后续启动可重试。模板读取也支持迁移遗留记录。

备份时需同时保存 SQLite 数据库及整个资源目录。改变根路径前，停止服务，将原资源目录完整复制到新目录，再修改配置并启动。配置变更不会自动搬移已经存在的资源。

当前保留历史资源，不自动清理删除或修改模板后不再使用的文件，以免破坏已有工作空间快照的引用。
