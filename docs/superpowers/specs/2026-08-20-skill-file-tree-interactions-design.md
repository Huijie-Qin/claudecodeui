# Skill 文件树交互优化设计

日期：2026-08-20

## 背景

技能市场和“我的技能”已经从弹窗迁移为工作区子页面。当前实现仍有三类不一致：市场状态沿用“安装”术语；移除与文件操作使用浏览器原生 `confirm` 和 `prompt`；详情文件树始终完全展开，不能在树中直接完成新建和重命名。

本次改动统一导入术语和危险操作样式，并把本地 Skill 的文件管理收敛到文件树内部。市场数据源、工作区 Skill 文件结构和后端 API 均保持不变。

## 目标

- 技能市场统一使用“已导入”和“可导入”。
- 市场 Skill、本地 Skill、文件和文件夹使用同一种应用内移除确认弹窗。
- 本地 Skill 的新建文件、新建文件夹和重命名在文件树中行内完成。
- 文件夹支持展开和收起。
- 保持现有权限、未保存内容保护、API 和文件安全校验。

## 非目标

- 不修改远端技能市场协议或数据结构。
- 不增加文件上传以外的新导入来源。
- 不支持通过重命名输入跨目录移动节点。
- 不调整 Skill 编辑器、Markdown 可视化或 ZIP 上传流程。

## 方案选择

采用组件拆分方案：从 `SkillsWorkspacePanel` 中抽出 `SkillFileTree` 和 `RemovalConfirmDialog`。

与继续把状态堆叠在主组件相比，组件拆分能将树结构计算、展开状态和行内编辑状态隔离；与 `contentEditable` 方案相比，受控输入框更容易处理聚焦、提交、取消和错误恢复。

## 组件边界

### SkillFileTree

`SkillFileTree` 负责：

- 将平面文件条目转换为有父子关系的树节点。
- 维护展开目录集合，初次加载默认展开所有目录。
- 根据展开状态只渲染可见节点。
- 维护一个行内操作草稿：新建文件、新建文件夹或重命名。
- 计算新建节点的父目录和重命名后的完整相对路径。
- 校验行内输入，并通过回调请求主页面执行 API 操作。

主页面继续负责：

- 权限判断和未保存内容保护。
- 调用现有工作区 Skill API。
- 刷新详情、文件内容和“我的技能”列表。
- 显示成功或失败信息。

### RemovalConfirmDialog

`RemovalConfirmDialog` 复用原技能市场移除弹窗的布局：危险图标、标题、说明、等宽目标路径、取消按钮和红色确认按钮。

弹窗通过统一目标描述支持三种操作：

- 移除市场导入 Skill。
- 移除本地创建 Skill。
- 移除 Skill 内的文件或文件夹。

界面统一使用“移除”，底层仍调用各自现有的 remove/delete API。

## 交互设计

### 市场状态文案

- `已安装` 改为 `已导入`。
- `可安装` 改为 `可导入`。
- 技能市场统计项 `已安装` 改为 `已导入`。
- “我的技能”中的来源标签 `市场安装` 保持不变，它描述来源类型而不是当前操作状态。

### 文件夹展开和收起

- 文件夹初次显示时默认展开，保持与当前全部可见的体验一致。
- 点击文件夹整行或左侧箭头切换展开状态。
- 收起目录后隐藏其所有后代节点，展开后恢复。
- 文件节点点击逻辑保持为选择并加载内容。
- 刷新详情时保留仍然存在的目录展开状态；新增节点的父目录自动展开。

### 行内新建

工具栏保留“新建文件”和“新建文件夹”按钮，但不再打开浏览器输入框。点击后在目标父目录下插入临时输入行并自动聚焦。

目标父目录规则：

- 选中文件夹：在该文件夹内创建。
- 选中文件：在该文件的父文件夹内创建。
- 没有选中项：在 Skill 根目录创建。

交互规则：

- Enter 提交。
- Esc 取消。
- 输入框失焦取消。
- 提交期间锁定当前输入，防止重复请求。
- 创建成功后刷新详情、展开父目录并选中新节点；新文件同时加载到右侧。
- 创建失败时保留草稿和输入内容，并在页面消息区域显示错误。

### 行内重命名

点击重命名按钮后，选中节点的名称替换为自动聚焦的输入框。只能修改当前节点的名称，父目录不变。

- Enter 提交。
- Esc 或失焦取消。
- `SKILL.md` 继续禁止重命名。
- 成功后刷新详情并选中重命名后的节点；如果重命名的是当前文件，右侧继续展示该文件。
- 失败时保留输入内容并显示错误。

### 名称校验

行内名称必须满足：

- 去除首尾空白后非空。
- 不是 `.` 或 `..`。
- 不包含 `/` 或 `\\`。
- 不包含空字符或控制字符。

前端校验用于即时反馈，后端现有路径安全校验继续作为最终边界。

### 移除确认

点击以下按钮时设置待移除目标并打开应用内弹窗，不再调用浏览器 `confirm`：

- 市场详情的“移除”。
- 本地 Skill 详情的“移除”（原“删除技能”）。
- 文件树中的文件或文件夹“移除”（原“删除”）。

弹窗展示完整相对路径。取消仅关闭弹窗；确认后锁定按钮并执行操作。失败时关闭加载状态、保留页面上下文并显示错误；成功后刷新对应列表或文件树。

移除当前文件后，详情自动选择 `SKILL.md`，如果不存在则选择剩余的第一个文件。移除整个 Skill 后返回相应列表。

## 状态与数据流

1. 主页面加载 Skill 详情并把文件条目交给 `SkillFileTree`。
2. 文件树根据条目和展开集合计算当前可见行。
3. 用户触发行内操作后，文件树产生经过校验的操作参数。
4. 主页面调用现有 API，并在成功后刷新详情和列表。
5. 文件树根据刷新结果恢复选中节点、展开节点或失败草稿。
6. 移除操作先进入统一确认弹窗，确认后才调用对应 API。

## 错误与并发处理

- 行内提交和移除期间禁用重复提交。
- API 错误继续使用页面内成功/错误消息区域展示。
- 后端返回的路径冲突、非法名称或权限错误原样转成可读错误消息。
- 行内操作不会绕过只读工作区限制。
- 切换页签、返回列表或切换文件时继续执行现有未保存内容保护。

## 测试方案

### 单元测试

- 市场状态文案映射为“已导入 / 可导入”。
- 平面条目生成正确的树结构和节点顺序。
- 收起目录后隐藏全部后代，重新展开后恢复。
- 根据文件夹、文件和空选中状态计算正确的新建父目录。
- 重命名仅替换 basename，并保持父路径。
- 名称校验覆盖空值、`.`、`..`、路径分隔符和合法名称。
- 移除弹窗为三类目标生成正确标题、说明和路径。

### 页面回归

- 市场列表、统计和详情显示新文案。
- 文件夹可以通过整行和箭头展开、收起。
- 根目录、文件夹内和文件同级位置均能行内新建。
- 文件和文件夹可以行内重命名，Enter、Esc 和失焦行为正确。
- 市场 Skill、本地 Skill、文件和文件夹均显示一致的移除弹窗。
- 移除、刷新和自动选择后右侧文件预览保持正确。

## 验收标准

- 技能页面不再为本次范围内的操作调用浏览器原生 `prompt` 或 `confirm`。
- 市场状态和统计不再出现“已安装 / 可安装”。
- 本地 Skill 文件管理可以完全在文件树中完成。
- 目录展开状态、选中状态和右侧预览在成功操作后保持一致。
- 类型检查、相关单元测试和本地浏览器回归全部通过。
