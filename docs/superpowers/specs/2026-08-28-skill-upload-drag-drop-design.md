# 技能 ZIP 拖拽上传设计

## 目标

在“我的技能 → 上传技能”弹窗中支持将单个 ZIP 文件拖入现有虚线上传区域，同时保留点击选择 ZIP、校验预览和导入流程。

## 范围

- 仅支持单个 ZIP 文件。
- 不支持拖入技能目录、多个文件或非 ZIP 文件。
- 不修改后端接口、表单字段、技能校验规则或导入来源标记。
- 不扩大为整个弹窗接收拖拽；只有现有虚线上传区域是有效投放目标。

## 交互设计

上传区域继续作为可点击的文件选择标签，并新增原生拖拽事件：

1. 文件进入或停留在上传区域时阻止浏览器默认打开文件的行为。
2. 有文件悬停时，高亮边框、背景和图标，文案显示“松开以上传 ZIP”。
3. 文件离开有效投放区域时恢复默认样式和文案。
4. 放下一个有效 ZIP 后，复用现有文件选择状态更新逻辑，展示文件名，并清空旧的预览与错误。
5. 上传校验进行期间禁用文件选择和拖放，避免校验对象在请求中途被替换。

## 文件校验与错误处理

前端在接收拖放文件时进行轻量校验：

- 没有文件：忽略，不改变当前选择。
- 多个文件：拒绝，并提示“每次只能上传一个 ZIP 文件”。
- 非 ZIP 文件：拒绝，并提示“仅支持 ZIP 文件”。
- 单个 ZIP：接受并交给现有后端预览接口进行内容、目录和 `SKILL.md` 校验。

ZIP 判定同时检查文件扩展名和浏览器提供的 MIME 类型；扩展名 `.zip` 作为兼容不同浏览器 MIME 行为的主要依据。拖放校验错误显示在现有弹窗错误区域，不使用浏览器弹窗。

## 组件与数据流

改动限制在技能上传界面及其可测试的文件选择辅助逻辑：

- `UploadSkillDialog` 管理拖拽高亮状态并处理 DOM 拖拽事件。
- 一个纯函数负责从 `FileList`/文件数组中判定有效 ZIP 或返回错误，供点击选择和拖放共同使用。
- `SkillsWorkspacePanel` 继续持有 `uploadArchive`、预览和上传错误状态。
- 文件被接受后仍通过 `FormData` 的 `archive` 字段调用现有 `workspaceSkills.uploadLocal`，之后沿用现有预览安装流程。

## 可访问性

- 上传区域继续可通过点击和键盘聚焦文件输入使用。
- 拖拽高亮只是视觉增强，不作为唯一上传方式。
- 错误文案继续在弹窗内容中展示，便于辅助技术读取。

## 测试

新增纯函数单元测试，覆盖：

- 接受一个扩展名为 `.zip` 的文件。
- 接受 ZIP MIME 类型且扩展名大小写不同的文件。
- 拒绝非 ZIP 文件。
- 拒绝多个文件。
- 无文件时不替换已有状态。

实现后运行 TypeScript 类型检查和技能市场相关回归测试。
