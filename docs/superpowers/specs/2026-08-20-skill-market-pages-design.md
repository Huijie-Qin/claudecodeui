# 技能页面改版设计

## 背景

当前技能市场通过工作区页头右侧按钮打开弹窗。新需求将技能能力改为与 MCP Tools、SQL Check 同级的正式工作区页面，并在页面内提供“技能市场”和“我的技能”两个二级视图。

设计参考 `scratch/designs/skill-market-v2/index.html`，但只复用与本需求有关的页面结构。分类、模板库、片段库、PR、调试、测评和版本治理不在本次范围内。

## 目标

- 用正式工作区子页面替代技能市场弹窗。
- 继续使用原技能市场数据源以及导入、更新、移除能力。
- 展示当前工作区 `.claude/skills/` 中的全部技能。
- 将本地技能明确分为“市场安装”和“本地创建”。
- 支持新建和上传本地技能；上传技能也归类为“本地创建”。
- 支持本地创建技能的完整文本文件管理。
- 统一市场技能和本地技能的文件树及文件可视化体验。

## 非目标

- 不根据名称或描述推断技能分类。
- 不在前端维护技能分类映射。
- 不新增“文件上传”来源类型。
- 不允许直接编辑市场安装技能。
- 不实现示例稿中的模板库、片段库、贡献、调试、测评、版本历史或管理后台。
- 不支持在详情页重命名技能根目录。

## 信息架构

### 顶层导航

新增工作区顶层页签“技能”，与 Chat、Files、CodeHub、MCP Tools、SQL Check 等页签并列。删除页头右侧用于打开技能市场弹窗的按钮，并移除弹窗挂载逻辑。

“技能”页面包含两个二级页签：

- 技能市场
- 我的技能

页面保存当前二级页签、搜索词、筛选条件、列表滚动位置、当前详情和选中文件。从详情返回时恢复原列表状态。切换工作区时清空详情和未保存编辑草稿，并加载新工作区数据。

## 标签与筛选

市场接口当前没有分类或标签字段，因此本次不展示“通用能力”“行业能力”等内容标签，也不提供内容分类筛选。

只展示可由真实数据确定的状态：

- 市场状态：可安装、已安装、待更新、冲突。
- 本地来源：市场安装、本地创建。
- 异常状态：解析失败、市场已下架。
- 辅助信息：市场版本、本地版本、创建者、文件数量。

“我的技能”的来源筛选为“全部 / 市场安装 / 本地创建”。未来市场接口提供稳定的 `tags` 或 `category` 字段后，再增加分类筛选。

## 技能市场

技能市场继续使用现有市场接口及分页、搜索能力。

页面头部展示标题、当前工作区、刷新按钮，以及“全部、已安装、待更新”汇总。列表行展示名称、描述、市场版本、创建者和真实状态。

列表操作如下：

- 未安装：导入。
- 已安装且无更新：移除。
- 已安装且有新版本：更新为主要操作，移除为次要操作。
- 与本地创建技能同名：显示冲突并禁止导入或覆盖。

点击技能进入正式详情子页面。市场内容始终只读。

## 我的技能

“我的技能”展示当前工作区 `.claude/skills/<name>/` 下的全部技能。页面头部展示“全部、市场安装、本地创建”汇总，并提供搜索、来源筛选、“上传技能”和“新建技能”。

来源定义：

- 市场安装：本地目录与当前工作区有效的技能市场导入记录匹配。
- 本地创建：本地目录不存在对应市场导入记录，包括页面新建和 ZIP 上传。

市场安装技能只读，支持更新和移除。本地创建技能支持编辑目录内所有文本文件、新增文件或文件夹、重命名、删除以及删除整个技能。图片和其他二进制文件可预览或下载，并可删除，但不可编辑内容。

## 统一技能详情

从“技能市场”或“我的技能”进入详情后使用同一套结构，复用当前技能市场弹窗的文件树和文件预览体验，但作为正式子页面呈现。

### 页面布局

- 顶部面包屑：技能 > 技能市场或我的技能 > 技能名称。
- 左侧：技能的完整文件树。
- 右侧顶部：名称、描述、市场版本、本地版本、创建者、来源、状态和可用操作。
- 右侧下方：当前文件的可视化或编辑区域。

默认选择 `SKILL.md`，切换文件时保留文件树展开状态。

### 文件呈现

- Markdown：默认渲染预览，可切换预览和源码。
- JSON、YAML、脚本及其他文本：代码高亮。
- 图片：直接预览。
- 不支持预览的二进制文件：展示文件名、大小和下载操作。

### 市场详情操作

- 未安装：导入。
- 已安装：移除。
- 待更新：更新和移除。
- 冲突：禁止导入并显示冲突目录。

更新前显示本地版本到市场版本的变化，并说明市场副本将被覆盖。更新成功后刷新市场详情、“我的技能”和文件树。

### 本地详情操作

市场安装技能的文件全部只读；有新版本时显示“待更新”，支持更新和移除。

本地创建技能提供预览和编辑模式，并支持：

- 编辑所有文本文件。
- 新增文件和文件夹。
- 重命名文件和文件夹。
- 删除文件和文件夹。
- 删除整个技能。

根 `SKILL.md` 不允许删除或重命名。存在未保存修改时，切换文件、返回列表、切换页签或切换工作区必须确认。保存失败时保留编辑内容。

## 新建技能

“新建技能”使用轻量表单收集：

- 技能目录名。
- 展示名称。
- 描述。
- 初始 `SKILL.md` 内容。

表单实时展示目标路径 `.claude/skills/<name>/`。服务端校验目录名、同名冲突和 `SKILL.md` frontmatter。创建成功后来源为“本地创建”，刷新文件树和 slash commands，并直接进入详情编辑状态。

## 上传技能

上传沿用 ZIP 工作流：

- ZIP 内必须且只能包含一个可识别的技能目录及 `SKILL.md`。
- 上传后先展示名称、描述、文件数量、目标路径和校验结果。
- 校验通过后才能确认导入。
- 同名目录存在时禁止覆盖。
- 导入后的来源统一为“本地创建”。
- 成功后刷新文件树和 slash commands，并进入技能详情。

## 数据模型与合并

技能市场接口保持现状。工作区技能 inventory 在保持现有字段兼容的前提下增加：

```ts
type WorkspaceSkillOrigin = 'market' | 'local';

type WorkspaceSkillMarketState = {
  origin: WorkspaceSkillOrigin;
  marketVersion?: number;
  localVersion?: number;
  updateAvailable?: boolean;
  remoteDeleted?: boolean;
};
```

服务端负责合并，不允许前端根据名称猜测来源：

1. 扫描 `.claude/skills/<name>/`。
2. 查询当前工作区的市场导入记录。
3. 目录与有效导入记录匹配时标记为 `market`。
4. 其余目录标记为 `local`。
5. 市场技能下架但本地目录仍存在时保留 `market` 来源并标记 `remoteDeleted`。
6. 市场记录存在但本地目录缺失时不出现在“我的技能”。

## 接口边界

现有技能市场接口继续负责：

- 市场列表、搜索和分页。
- 市场详情和文件内容。
- 导入、更新和移除。

工作区技能接口负责：

- 本地 inventory 和来源增强信息。
- 本地技能详情和文件树。
- 单文件内容读取。
- 本地文本文件保存。
- 新增文件或文件夹。
- 重命名文件或文件夹。
- 删除文件或文件夹。
- 新建本地技能。
- 删除整个本地技能。
- ZIP 上传预览和确认导入。

所有本地写接口必须在服务端校验目标技能来源为 `local`。市场安装技能即使通过直接请求也不能由本地文件接口修改。

## 文件安全与一致性

- 所有目标路径必须解析在 `.claude/skills/<skill-name>/` 内。
- 拒绝绝对路径、`..`、路径穿越和逃逸符号链接。
- ZIP 解压限制上传大小、解压后总大小、单文件大小、文件数量和目录深度。
- 拒绝 ZIP Slip 路径。
- 文本文件通过同目录临时文件和原子替换保存。
- 文件读取返回 revision，保存时携带 revision；磁盘内容变化时返回冲突，不静默覆盖。
- 保存 `SKILL.md` 前校验 frontmatter、技能名称和描述。
- 删除整个技能前二次确认并显示目标目录。
- 写操作成功后刷新项目文件树和 slash commands。

## 权限

- `owner` 和 `edit` 可执行市场导入、更新、移除及本地技能 CRUD。
- `view` 可浏览两个页面，但不能执行写操作。
- 前端禁用写按钮，服务端独立执行最终鉴权。
- 市场安装技能在任何角色下都不能通过本地文件接口编辑。

## 异常处理

市场与本地数据分别加载，互不阻断：

- 市场失败只影响“技能市场”，并提供重试。
- 本地扫描失败只影响“我的技能”，并提供重试。
- 单个无效技能仍出现在“我的技能”，标记“解析失败”，允许查看并修复 `SKILL.md`。
- 文件加载失败时保留目录树和元信息，文件区域提供重试。
- 保存失败时保留未保存内容。
- 更新失败时保留当前本地版本。
- 上传、新建或重命名冲突时显示具体目标路径并禁止覆盖。
- 异步操作显示加载状态并防止重复提交。
- 成功操作立即刷新相关列表和详情，并显示简短反馈。

## 响应式与无障碍

- 桌面端使用左侧文件树和右侧详情。
- 中等宽度缩窄文件树，内容区保持主导。
- 移动端将文件树放入抽屉，通过明确的“文件”按钮打开。
- 所有操作支持键盘访问和可见焦点。
- 图标按钮提供无障碍名称。
- 来源和状态同时使用文本，不只依赖颜色。
- 异步操作提供可感知的加载和结果反馈。

## 测试策略

### 服务端

- 市场导入与本地创建来源识别。
- 上传技能归类为本地创建。
- 市场下架后的本地来源保留。
- 本地文件新增、读取、保存、重命名和删除。
- 根 `SKILL.md` 删除及重命名保护。
- frontmatter 校验。
- 路径穿越、符号链接逃逸和恶意 ZIP 防护。
- 只读工作区拒绝写操作。
- 市场安装技能拒绝本地编辑。
- revision 冲突不覆盖磁盘内容。

### 前端

- 顶部技能入口和二级页签。
- 搜索、来源筛选和真实状态标签。
- 导入、更新和移除按钮状态。
- 文件树及 Markdown、代码、图片和二进制文件呈现。
- 本地文件完整管理流程。
- 未保存修改离开确认。
- 新建、上传、冲突和失败反馈。
- 从详情返回后恢复列表状态。
- 移动端文件树抽屉。
- 市场和本地数据独立失败。

### 端到端验收

1. 从市场导入技能后，它在“我的技能”中显示为“市场安装”。
2. 市场出现新版本后，市场和我的技能详情都提供更新入口。
3. 页面新建和 ZIP 上传的技能均显示为“本地创建”。
4. 本地创建技能可管理目录内所有文件，市场安装技能始终只读。
5. 删除或移除后，`.claude/skills/`、项目文件树和 slash commands 状态一致。
6. 市场或本地任一数据源失败时，另一页仍可使用。
7. 原技能市场弹窗和页头按钮被正式“技能”页面替代。
