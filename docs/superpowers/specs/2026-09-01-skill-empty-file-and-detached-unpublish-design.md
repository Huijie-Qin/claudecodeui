# Skill 空文件发布与本地下架状态修复设计

日期：2026-09-01  
状态：已确认

## 背景

技能编辑器新建文件时会写入真正的零字节文件。技能发布或发布更新会把该文件原样放入 ZIP，技能市场随后返回含义模糊的 `mismatch file suffix`，用户无法从提示中定位问题。

另一个问题是技能市场详情页把“可下架”复用了“可发布更新”的判断。用户删除自己已发布技能的本地目录后，绑定信息仍在，但 `canPublish` 会因为本地目录不存在而变为 `false`，导致下架按钮消失；重新导入使本地目录恢复后按钮才会出现。

## 目标

1. 通过技能文件树新建文本文件时，默认内容为一个换行符，而不是零字节。
2. 首次发布和发布更新在请求技能市场前统一拒绝真正的空文件。
3. 空文件错误必须指出首个问题文件，文案严格为：`<文件路径> 是空文件，技能市场暂不支持发布空文件。`
4. 下架能力只依赖发布绑定、创建者身份和工作区管理权限，不依赖本地目录是否存在。
5. 不放宽实际下架接口的服务端权限与确认校验。

## 方案比较

### 方案 A：创建时初始化换行，并在发布时兜底校验（采用）

新建文件默认写入 `\n`；构建首次发布或更新请求前检查本地文件列表，发现零字节文件立即返回结构化错误。这样正常新建流程不会触发市场限制，用户主动清空文件后也能得到准确提示。

### 方案 B：发布时临时为空文件补换行

本地文件仍为零字节，远端文件却包含换行，发布基线与实际市场内容不一致，后续差异预览会反复显示变化。不采用。

### 方案 C：从发布包中忽略空文件

远端会缺失用户创建的文件，属于静默数据丢失。不采用。

## 空文件处理设计

### 文件创建

- `createWorkspaceSkillEntry` 的默认文件内容改为 `\n`。
- 调用方显式传入内容时继续尊重传入值；显式传入空字符串仍可创建零字节文件，以保持底层接口语义清晰，并由发布校验负责提示。
- 当前技能文件树不传 `content`，因此 UI 新建文件会稳定得到一个换行。

### 发布校验

- 在 Skill 市场服务的共享归档构建路径校验待读取的文件，确保首次发布和发布更新使用同一规则。
- 以原始字节长度为准；长度为 `0` 即为空文件，只有换行符的文件不是空文件。
- 按现有文件排序检查，返回首个空文件，保证提示稳定且简洁。
- 返回 `400 SKILL_EMPTY_FILE_NOT_PUBLISHABLE`，错误消息为：`<相对路径> 是空文件，技能市场暂不支持发布空文件。`
- 校验失败时不调用市场保存、更新或发布接口，也不改变本地绑定和版本。

## 下架状态设计

### 服务端状态

- 市场列表、详情和发布状态中增加独立布尔字段 `canUnpublish`。
- `canUnpublish` 为真需要同时满足：本地绑定的 `bindingType` 为 `published`；绑定的 `createUserId` 与当前用户一致。
- `runtimeExists` 和 `imported` 不参与该判断。因此本地目录已移除但绑定仍在时，创建者仍可下架。
- `canPublish` 继续要求本地目录存在，不改变发布更新语义。

### 前端展示

- `canUnpublishSkill` 使用服务端 `canUnpublish`，并继续要求当前工作区可管理。
- 市场详情页不再用 `canPublish` 决定下架按钮。
- 普通市场导入、其他创建者的技能和无管理权限工作区仍不显示下架按钮。

### 实际下架

- 下架接口继续校验精确小写 `yes`、`published` 绑定、创建者身份和远端技能 ID。
- 查找绑定时兼容本地目录名与市场展示名不同的情况：除本地绑定键外，也可用该技能的远端 ID 定位绑定。
- 下架成功后只删除远端技能和本地市场绑定；本地文件存在时仍保持不变。

## 测试策略

- 工作区 Skill 文件树未提供内容时，新建文件实际内容为 `\n`。
- 显式传入内容时仍按传入值创建文件。
- 首次发布包含零字节文件时返回指定错误码和精确文案，且市场接口未被调用。
- 发布更新包含零字节文件时返回同样错误，且市场更新和发布接口未被调用。
- 仅包含一个换行的文件可以正常进入 ZIP，内容保持为 `\n`。
- 自己发布的技能删除本地目录后，市场详情返回 `canUnpublish: true`，前端显示下架按钮并能完成下架。
- 他人发布、普通导入及无管理权限场景保持不可下架。
- 本地绑定键与市场名称不同的已发布技能仍能通过远端 ID 下架。

## 验收标准

- UI 新建文件后直接发布不会再因零字节文件收到 `mismatch file suffix`。
- 用户把文件清空后，页面显示 `<文件路径> 是空文件，技能市场暂不支持发布空文件。`
- 空文件错误发生在任何市场写请求之前。
- 自己发布但已从本地移除的技能无需重新导入，市场详情仍显示下架按钮。
- 所有既有创建者权限、确认值、本地文件保留和发布差异逻辑保持不变。
