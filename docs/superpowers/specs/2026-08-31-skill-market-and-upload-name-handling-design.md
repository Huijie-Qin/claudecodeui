# 技能市场与本地上传名称处理设计

日期：2026-08-31  
状态：已确认，完成设计后直接实施

## 背景

技能市场目前能够在导入阶段识别技能名称重复，但历史接口仍会返回预计算的 `conflict` 状态。本地 ZIP 上传则把压缩包顶层文件夹名作为安装目录，即使 `SKILL.md.name` 已经提供了更明确的技能身份，也会出现“展示名称”和“本地目录”不一致的问题。

## 目标

1. 技能市场不在列表或详情中预先展示冲突，也不因预计算冲突禁用导入。
2. 用户点击导入后才进行名称重复判断；重复时明确告知无法导入。
3. “我的技能”本地 ZIP 上传统一以根 `SKILL.md.name` 作为目标目录名。
4. ZIP 顶层文件夹名不参与技能命名、目录命名或冲突判断。
5. 保留中文和其他 Unicode 名称，不改写 `SKILL.md` 内容。

## 方案比较

### 方案 A：manifest 驱动（采用）

解压并定位根 `SKILL.md`，解析 `name`，使用该值生成预览名、托管源目录和运行目录。压缩包顶层文件夹仅是结构容器。

优点是技能只有一个业务身份，安装后的目录、元数据和 `SKILL.md.name` 一致；不需要改写用户文件。缺点是升级后，同一个 ZIP 可能安装到与旧版本不同的目录，但这正是本需求的预期行为。

### 方案 B：保留 ZIP 目录并增加名称别名

继续使用顶层文件夹作为目录，只在元数据中额外保存 manifest 名称。该方案保留历史路径，但会继续存在目录身份与技能身份分离的问题，不采用。

### 方案 C：安装前改写 `SKILL.md.name`

使用 ZIP 文件夹名作为目录并同步修改 manifest。该方案会修改用户内容，也违反“目录与 name 一致且保留 name”的要求，不采用。

## 技能市场导入

- 列表和详情不渲染“冲突”标签、图标或警告文案。
- 导入按钮只受权限、已导入状态和请求进行中状态控制。
- 导入请求下载技能后，以根 `SKILL.md.name` 为优先名称；旧格式缺少 frontmatter 名称时兼容回退到市场名称。
- 工作区存在归一化后同名技能时，后端返回 HTTP 409、错误码 `SKILL_NAME_CONFLICT` 和冲突名称。
- 前端收到该错误码后显示单按钮弹窗：“工作区已存在名为「{name}」的技能，无法重复导入。”
- 目录占用但技能名称不同时，继续自动分配 `_2`、`_3` 等目录，不展示冲突。

## 本地 ZIP 上传

### 结构解析

- ZIP 仍必须只有一个顶层目录，且该目录内必须直接包含唯一的 `SKILL.md`。
- 继续保留 ZIP 路径穿越、文件数量、单文件大小、解压总大小和目录深度检查。
- 顶层目录的具体名称可以任意合法 ZIP 路径段；它不再进入预览 `name`、冲突判断、元数据或目标路径。
- 删除重复执行的、以顶层文件夹名决定技能名的代码和相关提示。

保留结构检查是安全边界，不属于“文件夹名判断”：系统仍需确定哪一组文件构成单个技能，并避免根文件、多技能目录或嵌套入口造成歧义。

### 名称与目标目录

1. 解压后解析顶层目录中的根 `SKILL.md`。
2. `name` 必须是非空字符串，并继续通过现有路径安全校验，拒绝 `/`、`\\`、控制字符、`.` 和 `..`。
3. 预览返回的 `name` 和 `displayName` 均来自 manifest 名称。
4. 安装时 `.cloudcli/skills/sources/<name>` 和 `.claude/skills/<name>` 都使用 manifest 名称。
5. `SKILL.md` 及压缩包内其他文件原样复制，不执行内容改写。

### Unicode 与冲突

- 原始名称经首尾空白清理后保留大小写和中文字符，用于实际目录和展示。
- 冲突比较使用 Unicode NFC 归一化并忽略大小写，防止组合字符或大小写差异绕过检查。
- 名称冲突仍返回 `SKILL_NAME_CONFLICT`，不覆盖已有目录。
- ZIP 文件夹名即使与已有目录重复，只要 manifest 名称唯一，就不会产生冲突，因为安装目标完全由 manifest 名称决定。

## 前端文案

- 上传框说明改为：“ZIP 须包含一个顶层文件夹及其根 SKILL.md；安装目录使用 SKILL.md.name，顶层文件夹名会被忽略。”
- 上传预览目标路径展示 `.claude/skills/<manifest-name>/`。
- 名称冲突继续在上传预览中明确阻止安装，避免覆盖。

## 测试策略

服务端覆盖：

- ZIP 顶层目录名与 manifest 名称不同时，预览和安装目录使用 manifest 名称。
- 中文 manifest 名称生成中文目录，文件内容保持不变。
- 两个不同 ZIP 顶层目录但相同 manifest 名称会被视为名称冲突。
- ZIP 顶层目录名与已有目录相同、manifest 名称不同时，可以正常安装到 manifest 名称目录。
- NFC/NFD 等价名称和大小写差异不能绕过冲突判断。
- 单顶层目录、根 `SKILL.md`、路径安全和大小限制测试继续通过。

前端覆盖：

- 技能市场没有冲突标签或基于 `conflict` 的按钮禁用。
- 市场名称冲突使用弹窗提示无法导入。
- 上传提示说明文件夹名会被忽略，预览路径使用 manifest 名称。

## 验收标准

- 市场技能重名只在点击导入后提示，且不会写入文件。
- 上传 `任意文件夹/SKILL.md` 且 manifest 为 `name: 中文技能` 时，最终目录为 `.claude/skills/中文技能`。
- 修改 ZIP 顶层文件夹名不会改变上传预览结果或安装目录。
- 名称冲突不会覆盖任何现有目录。
- 相关服务测试、类型检查和前端构建通过。
