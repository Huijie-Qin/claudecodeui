# Skill 发布入口与文件目录聚焦设计

日期：2026-08-20

## 背景

技能市场和“我的技能”详情已经使用左侧文件树、右侧概览的页面结构，但目前仍有三处体验不一致：文件树顶部的工作区路径被截断后无法查看完整内容；Skill 发布入口仍绑定在通用文件编辑器中；文件页面顶部的新建和上传操作始终落在项目根目录，不能复用用户在文件树中的目录上下文。

本次改动把发布能力收敛到“我的技能”详情，并为两个文件树补充明确的路径提示和目录聚焦行为。市场数据源、发布 API、租户请求头以及 DataAgent 服务已有的可见范围规则均保持不变。

## 目标

- 技能市场和“我的技能”详情可通过悬浮或键盘聚焦查看完整路径。
- 文件编辑器不再展示任何 Skill 发布入口。
- “我的技能”详情根据发布状态展示“发布”或“发布更新”，并完整复用现有发布流程。
- Skill 从本地移除后，市场版本仍然存在，并在技能市场中恢复为“可导入”。
- 文件页面顶部的新建与上传操作默认作用于当前聚焦文件夹，无聚焦时才作用于项目根目录。

## 非目标

- 不修改远端技能市场协议、市场数据模型或租户可见范围规则。
- 不增加撤回发布、删除市场版本或跨租户管理能力。
- 不改变 `SKILL.md` 中 `name`、描述、版本和创建者的解析规则。
- 不改变文件树右键菜单已有的定点创建与上传语义。
- 不让普通文件选择隐式改变当前聚焦目录。

## 方案选择

发布能力采用共享组件方案：从文件编辑器中抽出发布状态、发布操作和相关确认界面，由“我的技能”详情独占调用。

该方案相较于在详情页复制逻辑，可以确保首次发布、发布更新、远端更新拦截、差异预览和确认行为始终只有一套实现；相较于新增后端一键发布接口，可以保留现有完整发布体验并控制改动范围。

文件页面采用显式目录聚焦状态，而不是复用多选状态或当前打开文件。目录聚焦只表达顶部工具栏的目标位置，避免与文件勾选、文件预览和右键操作相互影响。

## 完整路径悬浮提示

`SkillFileTree` 顶部继续以单行截断形式展示目标路径，保持窄侧栏布局。路径区域支持鼠标悬浮和键盘聚焦：

- 悬浮或聚焦时，在路径下方显示自定义提示浮层。
- 浮层展示未经截断的完整路径，支持换行和长路径。
- 鼠标移开或失去焦点后隐藏。
- 浮层不占用文件树布局高度，不改变侧栏宽度。
- 技能市场详情和“我的技能”详情共用相同实现。

不使用浏览器原生 `title`，以便统一视觉样式、键盘行为和出现位置。路径元素提供可聚焦能力，并通过 tooltip 语义关联浮层。

## 发布入口迁移

### 文件编辑器

文件编辑器移除以下内容：

- “上传并发布”按钮。
- “发布更新”按钮。
- 仅为按钮服务的发布状态请求和提示入口。

打开 `.claude/skills/<skill>/` 下的文件时，文件编辑器只承担文件查看与编辑，不再承担技能市场发布操作。

### “我的技能”详情

发布按钮放在详情右侧操作区的“移除”旁边，并根据现有发布状态显示：

- 尚未发布：绿色“发布”，调用现有首次上传发布流程。
- 已发布且当前用户具有维护权限：显示“发布更新”，调用现有更新发布流程。
- 市场存在必须先导入的远端更新：保持现有更新提示与阻止发布行为。
- 无发布权限或不属于可维护范围：不展示可执行的发布按钮，保持现有权限边界。

发布操作始终针对磁盘中的完整 Skill 目录，而不是某个当前打开文件。

### 共享发布能力

抽取共享发布能力，包含：

- 获取发布状态并归一化按钮模式。
- 首次发布请求。
- 发布更新前的预览请求。
- 本地与市场版本的差异展示。
- 输入 `yes` 的发布确认。
- 市场存在更新时的阻止提示。
- 加载状态、错误反馈和发布成功后的刷新回调。

文件编辑器不再挂载该能力；“我的技能”详情在选中 Skill 后挂载，并在切换 Skill 或发布成功后重新读取状态。

### 移除后的市场状态

“移除”继续只删除工作区中的 `.claude/skills/<skill>`，不删除已经发布的市场版本。移除成功后刷新“我的技能”和技能市场数据，使对应市场卡片从“已导入”恢复为“可导入”。

### 租户范围

首次发布和发布更新继续调用现有 API，并原样携带现有租户代码、账户和认证请求头。普通租户内可见和 DataAgent 租户发布内容对所有租户可见的规则继续由现有 DataAgent 服务处理，前端不增加额外分支或复制数据。

## 文件页面目录聚焦

### 独立状态

文件页面维护 `focusedDirectoryPath`：

- 空值表示项目根目录。
- 非空值表示顶部工具栏的新建和上传目标目录。
- 该状态独立于复选框多选、当前打开文件和目录展开集合。

聚焦目录行使用轻量高亮，帮助用户在执行顶部操作前确认目标位置。目录即使被收起，仍保持聚焦状态。

### 设置与清除规则

- 普通单击文件夹：切换展开状态，同时将该目录设为聚焦目录。
- 普通单击文件：打开文件，但保留上一次聚焦目录。
- 点击文件树空白区域：清除目录聚焦，恢复项目根目录。
- 点击顶部根目录名称：清除目录聚焦，恢复项目根目录。
- 切换项目：清除目录聚焦。
- 刷新后聚焦目录已不存在，或该目录被删除：自动清除并恢复项目根目录。

### 顶部工具栏目标

顶部工具栏的四类操作统一读取 `focusedDirectoryPath`：

- 新建文件。
- 新建文件夹。
- 上传文件。
- 上传文件夹。

有聚焦目录时，将其作为创建父路径或上传目标路径；没有聚焦目录时使用空路径，保持项目根目录行为。创建或上传成功后保留聚焦目录，方便连续操作。

右键菜单继续以右键点击的目录为准确目标，不读取或覆盖当前聚焦目录。

## 状态与数据流

### 发布

1. 用户进入“我的技能”详情。
2. 页面根据工作区、Skill 名称和租户上下文获取发布状态。
3. 页面展示“发布”“发布更新”或相应阻止提示。
4. 首次发布直接读取完整 Skill 目录并调用现有上传发布接口。
5. 发布更新先获取预览，展示差异并要求输入 `yes`。
6. 成功后刷新发布状态、“我的技能”详情和技能市场列表。
7. 移除本地 Skill 后刷新两个列表，市场项回到“可导入”。

### 文件目录聚焦

1. 用户单击目录，文件树更新展开集合和 `focusedDirectoryPath`。
2. 顶部工具栏通过统一目标计算函数取得聚焦目录或根目录。
3. 新建操作把目标传给现有行内创建逻辑；上传操作把目标传给现有上传逻辑。
4. 文件树数据刷新后验证目标目录是否仍存在。
5. 目标存在则保留聚焦，不存在则回退根目录。

## 错误与并发处理

- 发布状态请求切换 Skill 时避免旧请求覆盖新 Skill 状态。
- 发布按钮在请求期间禁用，防止重复提交。
- 发布预览或发布失败时保留当前 Skill 页面，并通过现有页面消息或弹窗展示错误。
- 发布成功后即使市场列表刷新失败，也明确反馈发布结果，并允许用户重试刷新。
- 文件创建和上传继续使用现有路径安全校验与错误反馈。
- 聚焦目录失效时静默回退根目录，不向已不存在的路径发起写操作。
- 点击文件树内部按钮、右键菜单或行内输入框不触发空白区域的清除逻辑。

## 测试方案

### 单元与组件测试

- 路径截断时，悬浮和键盘聚焦均显示完整路径，离开后隐藏。
- 发布状态正确映射为“发布”“发布更新”或不可发布状态。
- 首次发布调用原上传发布接口，并传递完整 Skill 标识和现有租户上下文。
- 发布更新保留预览、差异确认和 `yes` 校验。
- 文件编辑器不再请求发布状态，也不再渲染两个发布按钮。
- 目录单击同时设置聚焦和切换展开；文件单击保留聚焦。
- 空白区域、根目录名称、项目切换和目标删除正确清除聚焦。
- 四种顶部操作均使用聚焦目录，无聚焦时使用根目录。
- 右键菜单仍使用右键目标目录。

### 页面回归

- 技能市场和“我的技能”详情中的长路径均可查看完整内容。
- 本地创建且未发布的 Skill 显示绿色“发布”，发布后切换为“发布更新”。
- 已发布 Skill 的更新差异和确认流程与迁移前一致。
- `.claude/skills/<skill>/` 文件编辑页不再出现任何发布入口。
- 移除本地 Skill 后，“我的技能”不再显示该项，技能市场对应项显示“可导入”。
- 聚焦多层目录后，顶部新建文件、文件夹及上传文件、文件夹均落在正确目录。
- 点击文件后继续向此前聚焦目录操作；点击空白或根目录名称后操作回到项目根目录。

## 验收标准

- 两个 Skill 详情页的路径提示一致、完整并支持鼠标与键盘。
- 发布操作只出现在“我的技能”详情，且首次发布与更新发布行为无回退。
- 现有租户发布范围和认证头保持不变。
- 移除已发布 Skill 的本地副本后，市场项恢复“可导入”。
- 文件页面四种顶部写入操作准确使用聚焦目录或根目录。
- 类型检查、相关测试和本地浏览器回归全部通过。
