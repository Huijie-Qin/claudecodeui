# 技能全量搜索实施计划

## 目标

让技能市场在全部已发布远端技能中搜索，让“我的技能”在当前工作区全部本地技能中搜索；两个视图统一只按名称、展示名称、描述和创建者进行忽略大小写的子串匹配。

设计依据：`docs/superpowers/specs/2026-09-01-skill-full-inventory-search-design.md`

## 实施原则

- 先增加失败测试，再修改实现。
- 保留技能市场无关键词时的现有分页请求，避免扩大普通浏览请求量。
- 有关键词时先获得完整远端候选集合，再过滤和分页；工作区导入记录只补充状态，不限制候选集合。
- 复用可测试的搜索函数，避免“我的技能”页面继续维护一份私有匹配逻辑。
- 保留工作区现有未提交改动，不覆盖或提交无关文件。

## 任务 1：固定技能市场全量搜索行为

涉及文件：

- `server/services/skill-market.test.js`

步骤：

1. 增加隔离的远端市场测试服务，构造多页已发布技能，并让目标未导入技能位于后续分页。
2. 断言搜索时 CCUI 拉取远端完整目录，而不是把关键词交给远端后只搜索单页。
3. 分别覆盖名称、展示名称、描述和创建者匹配，以及忽略大小写。
4. 覆盖先过滤后分页的 `total`、`totalPages` 和 `hasNextPage`。
5. 覆盖跨页重复记录去重。
6. 保留并补强无搜索词仍只请求指定远端页的回归断言。

完成标准：新增测试在旧实现上失败，并准确复现未导入技能不可搜索的问题。

## 任务 2：实现服务端完整市场目录搜索

涉及文件：

- `server/services/skill-market.js`

步骤：

1. 增加有上限的完整远端目录读取函数，使用空搜索词和较大固定页大小逐页读取。
2. 按远端稳定 ID 去重；缺少 ID 时使用规范化名称作为后备标识，并保留首次出现顺序。
3. 有搜索词时，对完整目录按名称、展示名称、描述和创建者执行忽略大小写的子串匹配。
4. 对过滤结果按请求的 `page`、`pageSize` 切片并计算真实分页信息。
5. 只对当前结果页补充导入、版本、本地修改和创建者权限状态。
6. 全量搜索路径不追加“当前页缺失的已导入技能”，避免突破页大小或重复；远端已删除的本地绑定不进入市场候选集合。
7. 无搜索词时保留现有远端分页及导入摘要兼容行为。
8. 完整目录达到安全页数上限但远端仍报告下一页时返回错误，避免用截断数据冒充全量结果。

完成标准：所有市场搜索测试通过，未导入且位于后续分页的技能可以命中。

## 任务 3：统一“我的技能”搜索字段

涉及文件：

- `src/components/skills-market/utils/skillFormatting.ts`
- `src/components/skills-market/utils/skillFormatting.test.ts`
- `src/components/skills-market/SkillsWorkspacePanel.tsx`

步骤：

1. 将工作区技能搜索函数收敛为只匹配 `name`、`displayName`、`description` 和 `createUserId`。
2. 增加市场来源、本地来源、解析异常技能的完整清单测试，证明来源和状态不会决定是否参与搜索。
3. 分别验证四个字段、大小写和首尾空白。
4. 增加反例，证明 kind、status、sourceType、parseError 和文件信息不会造成命中。
5. `SkillsWorkspacePanel` 复用该函数，再与来源筛选取交集，删除页面私有重复 matcher。

完成标准：“我的技能”完整本地清单按约定字段稳定过滤，两个工作区技能入口使用同一规则。

## 任务 4：回归验证

步骤：

1. 运行 `server/services/skill-market.test.js`。
2. 运行 `src/components/skills-market/utils/skillFormatting.test.ts` 及相关技能前端测试。
3. 运行 TypeScript 类型检查。
4. 对改动文件运行 ESLint。
5. 运行 `git diff --check` 并检查工作区，确认没有覆盖或提交用户原有改动。

## 建议提交拆分

1. `docs(skills): plan full inventory search`
2. `fix(skills): search complete skill inventories`

## 完成定义

- 未导入、位于任意远端分页的已发布技能可以在技能市场被搜索到。
- 当前工作区任意“我的技能”条目都能按名称、描述或创建者被搜索到。
- 两个视图均不搜索技能文件内容或状态、来源等非约定字段。
- 搜索分页、加载更多和空关键词普通列表无回退。
- 新增及相关既有测试、类型检查和针对性 Lint 全部通过。
