# 技能页面改版实施计划

## 目标

在不改变远端技能市场协议的前提下，将技能市场从弹窗迁移为工作区正式页面，增加“我的技能”视图，并为本地创建技能提供安全的文件管理能力。

## 实施顺序

1. 扩展工作区技能服务：合并市场导入记录，输出 `market/local` 来源、版本和下架状态。
2. 增加本地技能详情、文件读取、新建、保存、重命名、删除和技能创建/删除接口；所有路径操作限制在技能目录内，并拒绝修改市场安装技能。
3. 复用现有 ZIP 预览与确认流程，上传结果统一归类为本地创建。
4. 新建 `SkillsWorkspacePanel`：实现“技能市场 / 我的技能”二级页签、搜索、汇总、来源筛选和独立错误状态。
5. 将旧市场弹窗的分页、详情、文件树、导入、更新和移除逻辑迁移到正式页面。
6. 实现统一详情页：文件树、元信息、Markdown 预览、源码视图，以及本地技能文件 CRUD。
7. 在顶层导航注册 `skills`，移除页头市场按钮和弹窗挂载。
8. 更新中英文文案、访问控制与导航测试。
9. 运行工作区技能服务/路由测试、前端单元测试、类型检查和构建。

## 验证重点

- 市场导入技能在“我的技能”中稳定识别为“市场安装”。
- 新建和上传技能统一识别为“本地创建”。
- 市场技能的本地文件写接口返回 403。
- 文件路径穿越、根 `SKILL.md` 删除/重命名及并发覆盖被拒绝。
- 市场页与我的技能页能够独立加载和失败。
- 原弹窗入口完全移除，`skills` 页签可被持久化和恢复。
