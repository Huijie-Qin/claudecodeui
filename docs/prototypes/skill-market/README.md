更新：2026-09-14。沿用 CCUI 工作区技能页与真实聊天页的视觉结构；只演示本次会话的新增设计，不代表生产功能已经接入。

入口：[index.html](index.html)。可用本机静态服务预览：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/prototypes/skill-market
```

从仓库根目录启动后访问 http://127.0.0.1:8765/index.html。也可直接用本地浏览器打开 HTML；部分内嵌浏览器不允许 file URL，可使用本机服务。

## 当前规则

- 普通用户可见模板中心和片段管理，能查看和使用但不能维护库。
- 我的技能的「新建技能」下拉提供「直接创建 / 模板创建」；直接创建沿用表单，模板创建复用会话的模板弹框，选定后才进入会话，取消留在原页。
- 模板弹框、模板中心支持名称/描述搜索；片段管理支持名称/说明/正文搜索。三处搜索独立，输入非空时在框内右侧显示清除图标，无框外“清空”文字；点击后恢复全部结果并聚焦输入框，空输入隐藏图标，保留无结果提示。
- 会话底部「技能生成」与其他能力同排；选模板后 placeholder 为「请输入额外补充信息…」。
- 创建者初始为负责人，负责人指定 Skill 管理员；二者能发布/合并。管理员正常合并需有效非作者认可，负责人可以直接合并；所有角色禁止自我 Approve。
- evals/evals.json 保存全部用例，兼容 skill-creator 的 skill_name / evals / id / prompt / expected_output / files / expectations 数据结构。文件路径与上游一致。
- 手工、AI、会话保存的用例直接写入，无草稿确认。已发布用例不可删除。
- 运行全部逐例串行。自动优化为全量前测 → 修改自动保存 → 同一批用例全量后测，不提供采用/确认改动。
- 会话聊天输入框最小高度从 40 px 增至 112 px，搜索框高度保持原样。我的技能测评页将三个主操作放在“技能测评”标题行右侧，窄屏时按钮组整体换到标题下方；按钮仍为 38 px 高、间距 10 px。
- 详情按聊天页格式展示完整可见消息、工具、子任务和文件，不以判定摘要代替；运行全部单列，优化前后左右两列，窄屏局部横向滚动；另提供本次 Skill 文件差异。
- 优化不发布。直接发布仍需发布者本人当前测评通过；贡献提交/合并免测评，成功后市场显示未测评。
- 不区分 Skill 版本；导入更新按远端更新时间与成功导入对应时间比较。

## 建议体验路径

1. 默认林舟身份 → 片段管理 → 查看内容；模板中心 → 查看模板：两者都能访问，无新增/编辑/删除库的控件。
2. 我的技能 → 新建技能 → 模板创建，或聊天 → 技能生成：在弹框搜索并选择模板；也可从模板中心搜索后点击在会话中使用。填写 name 与业务字段，输入额外信息，发送后自动生成并保存。直接创建仍打开原有手工表单。
3. 当前会话输入 /新技能名称 具体任务，完成后点「保存为测评用例」，直接进入测评表；文件编辑中可看到 evals/evals.json。
4. 我的技能 → 周报助手 → 测评 → 添加验证场景。手工保存或 AI准备场景均直接追加；文件编辑可核对同一个 JSON 文件。
5. 运行全部：停留测评页看后台顺序执行，每条用例末尾查看预期/实际。默认示例第一条失败，其他条继续运行。
6. 自动优化：完整前测结束后模拟写入 SKILL.md，再运行全部；详情看优化前/后输出，查看 Skill 修改对比。没有采用按钮。
7. 周报助手 → 管理 → 配置管理员，指定陈然；切换陈然可看到发布按钮，但无指派管理员权限。本人运行当前内容通过后可模拟发布。
8. 销售汇总预置 Skill 管理员陈然；市场 → 销售汇总 → 贡献 → PR-028。周可为作者不能自我认可；陈然作为非作者可认可再合并。负责人林舟可直接合并。
9. 系统管理员可以维护片段/模板；此身份不自动获得每个 Skill 的发布权。

## 实现与演示边界

全部数据只在浏览器内存；刷新重置，无 localStorage、IndexedDB、外部 API 或真实远端操作。页面上的「落盘」通过 Skill files 对象模拟，不会修改用户真实 Workspace。生成、AI判断、工具/subagent/文件产物均为标注的预设演示，不可用于评价真实 Skill 性能。

当前 UI 调用文件化 API：readEval、writeEvalCase、generateEvalCase、saveInvocationEval、startFileEvaluation、stepFileEvaluation、releaseFileEligibility。旧 suite/草稿/采用引擎暂作为历史回归夹具保留，不是可达的当前界面入口。
