# 会话创建技能与优化结果对照

实现日期：2026-09-22。本次补齐第一阶段功能说明中的 3.1、3.2、公共片段自动参考和 7.5。下列验证使用隔离工作区及可控模型响应，不代表真实模型业务效果已验收。

## 用户操作

在会话输入区点击「技能创建」，描述用途、输入和期望结果，然后发送。系统自动生成名称、选择相关公共片段、校验并保存 `SKILL.md`，同时初始化空的 `evals/evals.json`。无需填写标识或确认保存。

创建过程中显示进度，可以停止；失败或停止时保留描述。名称冲突自动增加后缀，不覆盖已有技能。成功后在「我的技能」中查看，也可以使用 `/技能名 任务描述` 调用。

「保存为测评用例」仅针对当前会话创建成功后、再通过 `/技能名 任务描述` 调用的同一技能显示。沿用现有的调用完成及输入可复现校验；普通技能调用、其他会话创建的技能、创建前的调用均不显示。服务端在查询入口和实际保存时都校验会话、技能名称与创建/调用先后顺序，刷新后规则保持一致。旧调用缺少会话和时间依据时不补猜来源，需重新调用。

自动优化的用例详情显示左右对照：左侧固定本任务初始前测，右侧默认最新一轮后测；可切换查看本任务其他轮次。顶部显示固定预期，两列沿用会话式完整过程、评分及文件查看。窄屏在对照区域左右滑动。

## 实现边界

- 创建任务持久化到应用 SQLite，按租户、工作区、用户、会话隔离。新会话使用独立标识，普通聊天建立真实会话后关联创建记录；不同会话草稿互不带入。
- 创建调用内置 skill-creator 指令和现有模型服务配置（与测评相同的 Anthropic 兼容接口配置）。没有接入本机 Codex 登录，不需要 Docker 来生成文本技能。
- 模型生成进程没有工作区工具权限。公共片段在请求受理时冻结，分批选择相关项，服务端核对 ID，再传入选中正文。最终技能不依赖片段 ID 或在线片段服务。
- 当前生成产物是 `SKILL.md` 与空用例文件；不生成或执行任意脚本和附件，不宣称已完成业务测评。描述仅接收文本。
- 服务端重复检查工作区编辑权限和会话归属。合法 YAML 元信息、名称、大小和疑似凭据校验通过后，在技能目录内暂存并整体重命名；失败清理暂存目录。
- 请求标识防重复提交；提交日志允许识别重启前已经完成的文件写入。其他中断任务显示失败，不自动重放模型调用。
- 单用户单工作区同时一个创建任务；生成超时为 10 分钟，模型调用预算沿用当前运行器的限额控制。部署模型服务仍需有效凭据。
- 普通运行详情保持原入口；优化对照只使用本次任务内部各轮，不恢复或混入上一任务。

## 会话持久化修复（2026-09-22）

创建请求受理时即登记持久会话，并导航到可恢复的会话地址；描述、进度和结果仍从服务端创建任务加载，不依赖浏览器临时缓存。新会话在侧栏中可找回。创建完成后开始普通聊天时关联到实际模型会话，保留创建记录及先前的应用消息。

启动时兼容旧版只有草稿标识的创建记录，以及绑定到 pending 会话的记录。后者只在确有技能创建历史时显示在会话列表；普通 pending 会话继续隐藏。用户主动删除的会话不会因此恢复。

验证覆盖创建受理后恢复、完成后刷新、全新标签页恢复、旧 pending 记录找回、重复关联、多条创建记录、用户隔离及会话路由。页面实测已恢复此前 test 技能创建记录。
