# 主子代理循环 Hook 展示统一

## 改动

主代理原本将循环进度放在“执行过程 → 后置行为”中；子代理的进度和取消按钮在外层卡片，等待时后置行为区域为空。

现在两者复用同一后置行为渲染：状态、工具名、轮询次数、时间和“取消等待”位于同一区域。取消和超时保留明确的终态名称；窄侧栏中的轮询次数不折行，长工具名截断后可悬停查看。

- `src/components/chat/utils/hookFollowupPresentation.ts`：将子代理内联循环进度转换为只用于展示的后置行为，不修改原记录、不新增后台作业、不触发主代理恢复。
- `src/components/chat/view/subcomponents/MessageComponent.tsx`：移除子代理独有的外层进度和取消入口，共用后置行为渲染与按作业 ID 取消的逻辑。
- 原 MCP 工具详情继续显示首次结果；最终结果仍位于 Hook 卡片。Hook 执行状态和循环终态均按真实记录显示，未修改后端语义。
