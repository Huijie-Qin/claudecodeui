## 配置按钮无响应问题的复现与修复

用户反馈点击“配置个人变量”没有反应后，通过实际截图复现：弹窗已挂载且字段出现在可访问性树中，但设置面板遮住了弹窗。首次测试使用可访问性操作填表，没有确认弹窗截图和鼠标命中，因此漏掉此问题。

- 原因：共享 Dialog 的 portal 层级为 `50`，设置面板层级为 `9999`。输入框中心的 `document.elementFromPoint` 命中设置页 `MAIN`，而非输入框。
- 修复：共享 DialogContent 增加 `portalClassName`，个人变量弹窗指定 `z-[10000]`，同时提升遮罩与表单的层级，其他弹窗保持原默认值。
- 修复后重新构建并刷新实际测试页面，用 Playwright 点击“配置个人变量”，截图确认弹窗显示在设置页上方；两个输入框及取消、保存按钮的中心命中检查均通过。
- 取消后设置页保留，再次打开并留空保存成功；另一工作空间的启用开关也能打开可见弹窗，实际点击项目字段后输入成功，未填写必填凭据时保存按钮仍禁用。最终取消测试输入，回到主测试工作空间保留配置弹窗。
- 前端 TypeScript 检查和构建通过；相关文件 lint 无错误，共享 Dialog 原有 `react-refresh/only-export-components` 警告仍存在。
