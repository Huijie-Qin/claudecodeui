4. Required states

These states are first-class UX, not backend-only error strings.

State matrix
Available

Ready to install

The Admin preset is published and can be installed into the current workspace with one click.

Installing

Binding workspace

CloudCLI writes the Admin-managed preset into the workspace MCP config and relies on the workspace bind mount.

Installed

Ready for next Agent turn

The MCP server is available from /workspace/.mcp.json when the next Agent turn starts.

View only

No edit access

Workspace viewers can inspect installed servers but cannot install or remove them.
